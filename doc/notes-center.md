# 全局笔记中心

Library 的“笔记中心”（macOS 也可按 ⇧⌘N）汇集已有 Annotation。数据
仍由 `Annotation.id / spaceID / sourceID / snapshotID / Locator` 决定；同一来源
加入多个空间不会复制同一 ID，不同 ID 的有意重复记录也不会被合并。

## 查找与编辑

- 每页最多 200 条，界面默认 80 条；按不可变创建时间及 ID 使用 keyset 分页。
  可切换新旧排序，按来源、空间、类型、创建时间和多个标签同时筛选。
- 搜索完整摘录和用户笔记，支持中文、英文及字面标点子串。数据在独立
  `annotation_note_search` FTS5 投影中；短中文和标点使用该投影中的字面
  匹配，不借用来源正文索引，也不加入 Agent source 工具或 Provider 上下文。
  搜索工作在 GRDB reader 上，取消/代际检查阻止旧页覆盖新筛选。
- 首次打开及搜索防抖期间显示「正在载入笔记」，只有当前查询/刷新版本
  完成后才显示结果或空状态。取消的任务、旧查询和旧刷新版本不能结算当前
  画面；初次读取失败显示可重试状态，不显示「没有匹配的标注」。分页期间
  保留已载入的当前结果。查询未结算或读取中，导出及多选删除暂时禁用。
- 读取结果回执与「返回原文」等操作错误分开。读取失败不沿用上一查询的
  数量或重新启用导出；底栏明确显示结果暂不可用。旧查询、旧刷新版本、
  已替换或取消的原文打开操作，其迟到错误不能覆盖新的搜索状态。多个已
  打开的笔记窗口可共同接收同一当前查询的完成回执，不要求重复加载成功。
- 每次首屏读取开始即发布新的 pending 代际回执，界面直接投影当前回执，
  不缓存旧窗口的成功状态。因此快速切回原筛选不会让已清空的列表伪装成
  空结果或恢复旧数量。当前加载拥有者退出且没有替代读取时，显示「笔记
  载入已暂停」和重新载入按钮；暂停期间不允许导出或批量删除。
- 标签名称按 Unicode NFC、首尾/连续空白、大小写及全半角规范化。最多
  64 个字符，不接受控制字符。同名创建复用 ID；重命名碰撞必须确认合并。
  合并只转移并去重标签关系，不合并标注。删除标签只删除关系。
- 编辑只更改原 Annotation 的用户笔记、更新时间及标签关系，保留摘录、
  锚点与身份。按更新时间检查并发修改；旧编辑器和旧删除确认不能覆盖
  新修改。单条/多选删除均先显示范围并要求确认。Reader Inspector 复用同一
  编辑器与删除命令。

## 原文与位置

列表显示来源、空间、人可读位置及「当前版本 / 已重定位 / 位置待恢复」。如果
Annotation 已不是来源最新快照，会明确标为「历史版本」，并独立保留已重定位
或位置待恢复的事实，不谎称当前版本。编辑器的「定位详情」保留原始
`current / relocated / orphaned`、Snapshot、Adapter 和 Locator，以便核验；
这一显示层本地化不改变持久化枚举、锚点或既有 Markdown 导出状态字段。
“回到原文”先由现有 AdapterCoordinator 解析原 Annotation 快照，不刷新或
重新导入来源。失败时保留摘录与笔记并显示原因。Quick Look 仅承诺来源级。

原快照以明确的回看横幅呈现，不改写日常阅读进度，不启动索引或 Agent。
正常打开空间恢复原有进度行为。内容捕获仍受当前 presentation token 约束。

## Markdown 导出

macOS 在列表底栏常驻「导出 Markdown」原生按钮（⇧⌘E），不依赖 sheet
工具栏分组能否呈现第二个控件。无匹配标注时按钮仍可见但禁用，载入标注后
启用；刷新期间按钮保持可见但禁用，避免导出上一筛选的结果。iPhone 使用
独立工具栏项。导出不要求先勾选条目，范围由后续预览确认。

选择当前筛选、已选条目或一个空间；可选择包含用户笔记、原始网页地址。
先捕获一致的数据库读快照并预览数量、字段及索引，再通过系统目录选择器
明确授权目标位置。网页地址默认不导出，选择导出时仍去掉 query/fragment，
且拒绝含凭据的 URL。不复制书籍、附件、Provider 配置或 Agent transcript。
macOS Sandbox 使用用户选择位置的 read/write entitlement；导入原始材料的
书签仍是只读。权限门禁拒绝任意绝对路径、home-relative 或自动媒体写权限。

输出是一个新目录，其中有 `index.md` 和按来源分组的 Markdown 文件。
文件名采用规范化标题及来源 ID 哈希后缀，不接受路径。文字经过 Markdown/
HTML 转义，摘录和笔记不会作为图片或外部资源语法执行。输出顺序固定。
临时目录与目标在同一卷，完成后原子改名；同名默认 `(2)` 等新副本，永不
静默覆盖。失败/取消清理本次临时目录，原有导出不变。导出限制为 100,000
条或 128 MiB 摘录/笔记文字；超限需缩小范围，而不是截断内容。

回链格式为 `onereader://notes/v1`，只携带本地资料库、标注、来源、快照 ID。
参数集、长度、字符、版本及数据库身份均严格校验；没有任意文件路径或
私有正文，也不触发导入、联网或模型调用。另一设备没有原 Library 时会明确
报错，Markdown 仍保留可阅读位置。静态导出不与 Obsidian 双向同步，删除
Library 标注不会删除历史导出包。

## 存储与验证边界

独立的 `v12-annotation-notes-center` 迁移增加稳定 ID 标签、关系表、索引与
搜索触发器，以及随机的 `notes_library_id`。旧 ID、时间、快照、锚点与阅读
进度不变。搜索投影可由 `rebuildNotesSearch()` 从 Annotation 重建，不能以
删除用户标注修复搜索。来源移除仍沿用既有删除规则，关系通过外键清理。

自动回归覆盖迁移、标签碰撞、私有搜索隔离、10,000 条分页、并发编辑、
严格回链和导出转义/原子性。原生 macOS/iPhone 操作、跨格式可见定位、
VoiceOver 和重启闭环由集成验收单独记录；单元测试不代表这些门槛已通过。
